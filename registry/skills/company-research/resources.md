# Resources

## Search tools

- Exa (primary search) — used via integration for finding recent articles, blog posts, funding announcements
- Company website — always check directly for product, pricing, team, blog

## Public data sources

- Crunchbase — https://www.crunchbase.com/ — funding rounds, investors, team
- LinkedIn — headcount, hiring velocity, key people
- G2/Capterra — customer reviews, feature comparisons
- SimilarWeb — traffic estimates (take with grain of salt)
- App Store / Product Hunt — launch history, reviews
- GitHub — for dev tools, check stars, contributors, activity
